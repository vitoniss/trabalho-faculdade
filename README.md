# Inventory IT - Sistema de Rastreamento de Equipamentos

## Que que eu fiz?

Um sistema web completo para rastrear a alocação de equipamentos de TI em laboratórios.

### Funcionalidades

Cadastro de Laboratórios
Cadastro de Equipamentos
Listagem com Relacionamento
Select Dinâmico

### Tecnologia usadas

No backend: Java Servlets (Jakarta EE 6), JPA/Hibernate 6, H2 Database
No front: JSP com JSTL, Bootstrap 5
Framework: Apache Tomcat 11
E pra build: Maven (pom.xml fornecido)

## Pré-requisitos

JDK 17+ 
Maven
Tomcat 11
